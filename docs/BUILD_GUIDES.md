# Kotonoha Cross-Platform Build Guides

This document indexes all platform-specific build guides for the Kotonoha engine.

3. **[iOS](BUILD_IOS.md)**: Building and running iOS apps using the native Xcode project.
4. **[macOS](BUILD_MACOS.md)**: Generating standalone macOS `.app` application bundles via CMake or Xcode.
