# Summer Radish Vacation!!

[English (US)](README.md) | **Português (Brasil)**

Port nativo que lê os CMP originais, com execução de roteiros e interface próprias.

**Estado:** Comportamento original completo e todas as rotas ainda não foram certificados.

## Compilação

```sh
cmake -S . -B build -DKOTONOHA_BUILD_SUMMER=ON
cmake --build build --target SummerRadish
```

## Dados do jogo

Forneça os pacotes CMP originais de uma instalação legítima.
Use o launcher ou passe `--summer /caminho/para/dados` ao executável. Nunca versione dados comerciais.
