Place Pure Mail (PMAILDVD) game data here or point the launcher to your
retail disc/folder.

Expected layout (from the original disc):
  data/pack/script.dat
  data/pack/graphic.dat
  data/pack/sound.dat
  data/pack/voice.dat
  data/setup.ini
  (and other original files)

Kotonoha does not ship game data. Use your own legally obtained copy.
