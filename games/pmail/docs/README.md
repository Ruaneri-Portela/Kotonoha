# Pure Mail technical notes

**English (US)** | [Português (Brasil)](README.pt-BR.md)

These notes describe **specific reverse-engineering findings** from the original DVD executable and assets. They are not proof of complete game parity.

- [Animations](ANIMATIONS.md): two `.anim` structures, SYS 51 presets, lip movement, validation.
- [Audio parity](AUDIO_PARITY.md): original PCM format, ADP codecs, mixer events, fades.
- [Textbox](TEXTBOX.md): WAKUH/WAKU/BOT layering, tint, cursor and auto timing.

Original hashes, byte offsets and test results remain in the research records. Start with the [port overview](../README.md) for current limitations.
