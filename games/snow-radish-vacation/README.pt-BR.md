# Snow Radish Vacation!!

[English (US)](README.md) | **Português (Brasil)**

Port nativo ADV3 jogável com gráficos, áudio, mapa, diálogo e saves.

**Estado:** Tempos dos efeitos e paridade de todos os cenários ainda exigem investigação.

## Compilação

```sh
cmake -S . -B build -DKOTONOHA_BUILD_SNOW=ON
cmake --build build --target SnowRadish
```

## Dados do jogo

Forneça os pacotes originais DATA/PACK, incluindo SCRIPT.DAT.
Use o launcher ou passe `--snow /caminho/para/dados` ao executável. Nunca versione dados comerciais.
