# Example

**English (US)** | [Português (Brasil)](README.pt-BR.md)

Small reference application for the shared scene, input, and visual-novel components.

**Status:** Demonstration, not a commercial-game compatibility target.

## Build

```sh
cmake -S . -B build -DKOTONOHA_BUILD_EXAMPLE=ON
cmake --build build --target Kotonoha
```

## Game data

No commercial game files are required.
Run the built demonstration executable. Never commit commercial game files.
