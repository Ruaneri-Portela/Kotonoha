# Example

[English (US)](README.md) | **Português (Brasil)**

Aplicação de referência para cenas, entrada e componentes de visual novel do motor.

**Estado:** Demonstração, não um port de jogo comercial.

## Compilação

```sh
cmake -S . -B build -DKOTONOHA_BUILD_EXAMPLE=ON
cmake --build build --target Kotonoha
```

## Dados do jogo

Não exige dados comerciais.
Execute o demonstrativo compilado. Nunca versione dados comerciais.
