# Arte personalizada de Display Options do School Days

[English (US)](README.md) | **Português (Brasil)**

A página Display Options personalizada usa PNGs/CMAPs criados pelo usuário de uma fonte privada de compilação. A arte comercial não é distribuída no Git.

- `Option_Display.png` e `Option_Display_Chip.png` são o painel e o atlas personalizados.
- Os CMAPs personalizados de Display são necessários; `display_options_controls.json` documenta as 22 regiões de controle.
- General/Sound continuam usando os CMAPs do jogo original. Não modifique `Packs/System.GPK`.
- Windows e Android podem incorporar a UI aprovada diretamente no binário nativo. Overrides externos continuam opcionais. Consulte as [instruções atuais de compilação](../docs/configuration/display-options/README.pt-BR.md).

Consulte a [investigação original](../docs/DISPLAY_OPTIONS_USER_ART_2026-11-05.md) e as [evidências de integração](../docs/PR_PARITY_CONSOLIDATION_2026-11-05.md).
